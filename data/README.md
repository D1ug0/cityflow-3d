# Геоданные центра Москвы

`moscow-map-extract.json.gz` — ограниченная выборка слоёв `transportation` и `building` векторных тайлов [OpenFreeMap](https://openfreemap.org/), схема [OpenMapTiles](https://openmaptiles.org/), данные © [участники OpenStreetMap](https://www.openstreetmap.org/copyright). Данные OSM распространяются по [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Источник и attribution сохранены внутри архива. Выборка: `planet/20260906_080001_pt`, zoom 14, район 37.588–37.633 E / 55.748–55.776 N. Векторные тайлы имеют квантование и могут отличаться от более свежей растровой подложки.

Обновление исходной выборки требует сети:

```sh
node scripts/download-map-data.mjs
```

Воспроизводимая локальная сборка данных приложения:

```sh
python3 scripts/build-map-data.py
```

Генератор сохраняет реальные вершины улиц, учитывает доступный `oneway`, исключает мосты/тоннели и участки рядом со зданиями. Находит сильно связную компоненту дорожного графа и замкнутые пути через опорные точки; искусственные прямые соединения между улицами не добавляются. Для кузова предусмотрен отступ от зданий. Данные в `public/data/roads.geojson`, `routes.geojson`, `buildings.geojson` производны от указанного источника.

Это не навигационный движок: тайлы не содержат полного набора правил поворотов, ограничений доступа и полос. Высота здания берётся из `render_height` OpenMapTiles и может быть оценочной. Автомобили движутся по осевым линиям улиц; светофоры, дистанции между машинами и перестроения пока не моделируются.
